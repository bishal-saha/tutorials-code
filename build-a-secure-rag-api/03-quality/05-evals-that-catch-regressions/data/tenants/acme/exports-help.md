# Exporting your data

You can export any dashboard or dataset as CSV or Parquet from the Export menu. Exports run in the background and you get an email with a download link when the file is ready.

## How long an export takes

Most exports finish within a few minutes. Very large datasets can take up to an hour. The status page under Settings > Exports shows each export as queued, running, complete or failed.

## If an export fails

Open Settings > Exports, select the failed export and choose Retry. If it fails again, contact support with the export id shown on that page. Error code ERR-2210 means the export was larger than your plan allows; filter the dataset or ask an admin to raise the limit.
